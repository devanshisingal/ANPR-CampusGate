5.2 Exact Root-Cause Analysis of All 6 Failures & Constraints
  1. `test_parseq_dataset.py` (1 failure) & `test_super_resolution.py` (2 failures):
     Pre-existing unit test drift vs refactored fallback signatures. Zero
     runtime impact on active CPU pipeline (`sr_threshold_px = 0`).
  2. `test_dashboard_smoke.py` (3 failures in Streamlit `1.67.0` AppTest):
     (a) 2 tests call `at.get("imgs")` instead of Streamlit 1.67.0's `at.get("image")`.
     (b) 1 date-filter test seeds synthetic timestamps (`Sept 12`) older than
         the dashboard's default `"Last 7 days"` filter (`2026-11-11`).
  3. Sandbox vs Host Execution Behavior:
     Any pytest invoking FastAPI `TestClient` or Streamlit `AppTest` blocks on
     restricted sandbox loopback sockets, requiring host execution or `-k`
     exclusion of ASGI test classes inside sandboxed CI.
